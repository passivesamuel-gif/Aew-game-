# AEW Animated Wrestler Models

This package contains two separate, skinned GLB character exports derived from the original MJF and Will Ospreay models. The files contain no ring, arena, lighting, or camera objects. Each GLB preserves the original high-resolution character mesh and material appearance and includes that wrestler’s animation library as separate clips.

The Blender Draco encoder was unavailable in the export environment, so the GLB geometry is not Draco-compressed. The ZIP package itself uses lossless DEFLATE compression; no mesh or texture quality was reduced.

## Files
- MJF_Wrestler_Animated_HQ.glb — 24 animation clips
- Ospreay_Wrestler_Animated_HQ.glb — 27 animation clips

## Notes
The clips are reusable animation assets, not a gameplay runtime or a guarantee of collision-free full-match choreography. The refined paired snap suplex remains an unfinished blockout; review it before using it as a final match move.
